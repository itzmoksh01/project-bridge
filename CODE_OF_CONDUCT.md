# Community Code of Conduct

We want participation in Project Bridge to be welcoming, respectful, constructive, and focused on improving the project for everyone.

## Expected behavior

- Be respectful and assume good intent while still addressing harmful behavior clearly.
- Critique ideas and implementation, not people.
- Give actionable feedback and explain technical trade-offs.
- Welcome newcomers and help them understand project conventions.
- Protect privacy: do not publish credentials, private source code, customer information, or identifying data.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private information without permission.
- Deliberately introducing malicious instructions, hidden network calls, credential theft, or destructive behavior.
- Spam or repeated disruptive conduct.

## Reporting

Report conduct concerns privately through the contact method listed on the repository maintainer's GitHub profile. Do not use public issues for sensitive reports.

Maintainers may edit, remove, or reject contributions that violate this code of conduct and may restrict participation when necessary to protect the community.
